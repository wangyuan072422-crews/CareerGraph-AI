# Resume Guidance

## Tailor the resume to the role

Mirror the job description's most important skills only when you have real evidence for them. Put the strongest relevant evidence near the top. Use concrete action verbs and describe what you built, the technical choices you made, and the result.

Prefer bullets such as: "Built a multi-agent workflow that routes requests, persists conversation state, and falls back safely when a model or database call fails." This explains the implementation and its engineering value without inventing metrics.

## Quantify outcomes honestly

Add numbers only when they are accurate. Useful measures include latency, test count, supported document count, error rate, or time saved. If you do not have a reliable metric, show scope and complexity instead of inventing an improvement percentage.

## AI application project checklist

A credible portfolio project should show real retrieval or tool use, persistent state, a clear graph or service boundary, automated tests, failure handling, and runnable setup instructions. A README should include an architecture diagram, one end-to-end example, test commands, and known limitations.
